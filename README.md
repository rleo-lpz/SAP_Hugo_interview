# SAP_Hugo_interview

Reposity containing the program, notes and read me file for SAP interview

To run this program, please follow the next instructions

1- Open powershell terminal and install hugo, use "winget install Hugo.Hugo.Extended"
2- Verify everything correct by checking the version, use "winget list Hugo"
3- After everything is correct, download the github repo into the same folder of your choice, for convenienve lets assume the folder name is "PEANUTS"
4- In the powershell terminal, access "PEANUTS" folder, use "cd C:\path\PEANUTS"
5- run the server using "hugo server"
6- Enter the localhost that pops into a browser, example "https://localhost:111111111/Home"
7- Enjoy the project, feel free to move my code hahaha, nothing will explode (I hope so, maybe???)
